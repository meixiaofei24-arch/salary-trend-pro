# 薪资趋势Pro V2.1 · 官方数据优先

默认展示人工核验的政府公开工资统计快照。保留 V2.0 的 43 城市、14 岗位模拟演示模式，真实与模拟模式独立，缺失真实数据绝不回退到模拟值。

## 已收录数据

截至本站核验日期 **2026-10-29**，收录国家统计局全国年度数据和 7 城市公开统计：上海、北京、深圳、广州、苏州、杭州、重庆。不同城市收录年份、口径不相同；这不是全国完整排名，也不宣称这些都是各市最新发布数据。

- 2025 年非私营单位：深圳、杭州、广州、苏州、重庆；私营单位同样收录这 5 城。
- 上海：2021–2024 年私营／非私营，来自上海统计年鉴2025表2.23。
- 北京：2018–2025 年全口径城镇单位就业人员平均工资，仅用于社保缴费基数上下限核定。独立口径，不混入私营／非私营排行。
- 全国：2023–2025 年私营／非私营；只作全国趋势，不参与城市排名。
- 细分招聘岗位：尚未接入真实数据。官方模式仅提供搜索、数据状态与收藏；原岗位区间和模拟趋势在演示模式保留。没有通过城市系数推算真实岗位工资。

每条记录有统计年份、原始年工资、币种单位、统计口径、发布机关、官方链接、发布日（如原文提供）、核验日和样本数状态。样本人数未提供时为 `null`。页面可在年平均工资和年工资÷12折合月均之间切换；后者不是实际月发工资或到手工资。

## 功能

同年份同口径排行、缺失城市说明、城市和岗位搜索、真实年度趋势、共用纵轴的城市对比、模式隔离收藏、包含模式／年份／口径的分享链接、自定义扣除计算器。年度趋势只显示已收录年份，不制造月度曲线；缺失年度不连线。计算器独立于统计数据，默认比例为演示参数，不提供城市社保或个税政策核算。

旧浏览器 `salary-favs` 收藏迁移为模拟收藏，不会悄悄变成官方数据收藏。搜索和计算不上传服务器。

## 数据维护

`official.json` 是主数据；`official-data.js` 是从它生成的浏览器快照。官方链接和统计说明可在网站“我的”页查看。

1. 从统计局／政府原文核验数值、统计年度、就业／从业人员口径、单位类型、单位和覆盖范围；不要把在岗职工、居民收入、社保全口径或招聘薪资混用。
2. 更新 JSON，保留每条记录对应的官方来源与核验时间。只收录明确公布的值，不从增速反推、不插值，不将“未核验”写成“官方未发布”。
3. `python3 check_sources.py` 抓取已知官方页并检查数字是否出现，结果保存在 `work/source-checks.json`；不会改动工资值。数字出现并不替代人工语义核验。网络或页面变动时明确失败，不覆写数据。
4. `python3 check_sources.py --export-js` 重新生成前端快照，再运行下方检查并发布。

目前是静态快照，**没有实时数据接口或定时自动更新**。来源网站可能有访问限制或调整，遇到失败需人工复核。未接入商业招聘平台，不绕过登录或验证码。
