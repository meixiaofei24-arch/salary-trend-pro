# 薪资趋势Pro V2.2

本次扩展：民政部337个内地地级行政区及直辖市目录、31省筛选、同口径工资同比增长、增长排序、五险一金独立政策页、年度缴费基数上下限变化、可分享的政策城市和年度。

**当前收录进度（2026-10-29）：工资77城市、306条年度/口径记录（含全国）；2026政策24省级地区至少一项基数，加北京、南充住房公积金。目录覆盖不等于数值完整覆盖。** 未核实项标记待核验，不插值、不采用商业汇编的估算数字。完整缺口在 `coverage.json`。

目录来源：民政部国家地名信息库公开行政区划接口。范围含293地级市、4直辖市、30自治州、7地区、3盟；不含县级市、港澳台。工资来自各政府统计公报、统计部门答复与统计年鉴，黑龙江2025年鉴2-12/2-15表逐项核对了地区及年度列。保留来源URL和摘录；就业/从业人员为就业人员统计，不收录仅在岗职工值。来源页不提供可结构化日期时保留null，样本量null仅表示本站未结构化收录。

工资增长公式：同城、同口径、相邻年度 `(本年/上年-1)*100`；缺去年不跨年比较、不按0增长；名义增长未扣除物价。基数增长对比同险种已公布年度版本，并同时显示双方适用期，不推定全年适用。政策页的2025/2026是文件所属年度，不是任意日期自动判定器。

`benefits.json` 的基数按省/市及险种分别收录，养老基数不默认套医保/公积金。来源见每项链接；国家法定工伤和生育个人不缴费单独标注，不计入地方政策核验覆盖。单位费率未知保留null；医保包含生育时明确合并，禁止重复计费。北京历史费率标注实际适用到2025年6月，不自动沿用到2026。现未形成完整费率历史，计算器仍为用户自填比例估算，不能视为各城精确到手工资。附加大病、长护、行业浮动费率等未完整收录。

数据维护：`official.json`、`directory.json`、`benefits.json` 为主文件，对应 `*-data.js` 必须精确同步。`coverage.json` 需随主数据更新。新增数据先核对原文地域、就业口径、年度及生效区间；二手站点仅作查找官方原文的线索，不作为数字来源。`node --test data.test.cjs` 验证数据唯一性、来源、337目录、同口径增长与险种隔离。

## 已收录数据

收录77个目录地区的不同年度与口径，2025年非私营可比较城市36个。完整清单和每条原文见 `official.json`；缺口见 `coverage.json`。北京2018–2025全口径社保参考独立展示；全国2023–2025私营/非私营仅用于全国趋势。各市年度范围不同，不宣称均为最新数据。

每条记录包含统计年度、年工资、单位、口径、官方URL和核验日期。发布日未结构化时为null，样本数null仅表示本站未收录。细分招聘岗位尚无真实数据，不能用城市平均工资乘系数推算；演示模式保留43城、14岗位的模拟数据。

## 功能

同年份同口径排行、缺失城市说明、城市和岗位搜索、真实年度趋势、共用纵轴的城市对比、模式隔离收藏、包含模式／年份／口径的分享链接、自定义扣除计算器。年度趋势只显示已收录年份，不制造月度曲线；缺失年度不连线。计算器独立于统计数据，默认比例为演示参数，不提供城市社保或个税政策核算。

旧浏览器 `salary-favs` 收藏迁移为模拟收藏，不会悄悄变成官方数据收藏。搜索和计算不上传服务器。

## 数据维护

`official.json` 是主数据；`official-data.js` 是从它生成的浏览器快照。官方链接和统计说明可在网站“我的”页查看。

1. 从统计局／政府原文核验数值、统计年度、就业／从业人员口径、单位类型、单位和覆盖范围；不要把在岗职工、居民收入、社保全口径或招聘薪资混用。
2. 更新 JSON，保留每条记录对应的官方来源与核验时间。只收录明确公布的值，不从增速反推、不插值，不将“未核验”写成“官方未发布”。
3. `python3 check_sources.py` 抓取已知官方页并检查数字是否出现，结果保存在 `work/source-checks.json`；不会改动工资值。数字出现并不替代人工语义核验。网络或页面变动时明确失败，不覆写数据。
4. `python3 export_data.py` 重新生成全部前端快照和收录进度，再运行下方检查并发布。

目前是静态快照，**没有实时数据接口或定时自动更新**。来源网站可能有访问限制或调整，遇到失败需人工复核。未接入商业招聘平台，不绕过登录或验证码。
