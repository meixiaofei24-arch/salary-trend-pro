# 薪资趋势Pro V2.0

纯静态中文薪资观察演示，适用于 GitHub Pages，无构建步骤，无外部脚本依赖。

## 功能
- 43 个中国城市模拟月薪排行，支持城市筛选和升降序。
- 14 类岗位的全局搜索、城市岗位组合查询、详情和模拟区间。
- 6 / 12 / 36 月趋势、详情趋势，SVG 图表和可展开数值表。
- 同岗位双城市对比，趋势统一纵轴，支持分享对比状态。
- 自定义社保、公积金比例和预估税额的月薪扣除估算，包含数值边界校验。
- 浏览器本地收藏，支持删除和存储异常降级；兼容 V1 收藏键。
- 原生分享 / 复制链接 / 手动复制降级；详情和对比支持哈希直达及刷新。
- 移动端和桌面布局、表单标签、键盘焦点。

## 数据说明
**所有城市与岗位薪资、区间、趋势和排名均为模拟数据**，不代表真实市场，不具备官方统计意义，也不覆盖所有城市。模拟基础指标是手工设定值，城市岗位值为岗位基础值 × 城市基础值 / 10000；区间为指标的 80%–120%；趋势采用确定性正弦公式，仅展示交互效果。第 N 月是演示序号，不是真实日历月份。

工资计算器是自定义扣除工具，不提供真实个税、社保或公积金政策核算；演示默认参数不代表任何城市政策，实际工资以工资单为准。未接入真实数据服务，不上传搜索、收藏和计算输入。收藏保存在本机浏览器。

## 预览与部署
使用任意静态服务器托管仓库根目录，例如 `python3 -m http.server 8765`。GitHub Pages 从 `main` 分支根目录发布即可。`index.html`、`styles.css`、`app.js` 使用相对路径，可运行在 `/salary-trend-pro/` 子路径。

## 验证
`node --check app.js` 检查语法。浏览器检查排行筛选排序、搜索有结果/无结果、周期切换、岗位城市联动、详情收藏与刷新、直达分享、对比、计算器正常/错误输入和窄屏布局。
